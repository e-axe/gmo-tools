# GMO TOOLS

営業のための軽量な計算・整形ツール。GitHub Pagesで配信する静的サイトです。

## ツール

- 生産性・時給：実績とクール数から自動計算、次の時給までの不足額、時給テーブル、コピー。
- 対稼働：対象年月と基準日の選択、営業日ベースの期待進捗、会社の休日・出勤日調整、コピー。
- 電話番号整形：日本の番号形式データによる市外局番の区切り、一括処理、行順保持、要確認・変換不可表示、コピー。

トップページから生産性・時給を直接操作できます。上部の共通ナビでツールを切り替えます。既存の `seisansei.html`、`taikadou2025.html`、`bangou_henkan.htm` のURLも維持しています。切替中の入力は同じ画面内で保持し、再読み込みでクリアします。入力内容の永続保存や外部送信は行いません。

## 計算基準と更新

### 時給

`src/calculations.mjs` の `WAGES` は旧サイトの設定を引き継いでいます。適用開始日・最新制度との一致は未確認です。制度の改定時はここを更新してビルドしてください。生産性の分母は入力したクール数をそのまま使用し、有給・残業などの控除は自動で行いません。必要実績と不足額は1円単位で切り上げ表示、ランク判定は表示丸め前の値を使用します。

### 営業日・祝日

`src/holidays.json`：内閣府の祝日CSV（国民の祝日・休日）、2026-10-09取得。2020〜2027年を収録。収録期間外の年は選択できません。

- 出典：https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html
- CSV：https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv

土日・祝日を除外し、追加休業日・追加稼働日を反映。基準日を含めて計算します。今月の基準日は日本時間で昨日まで、過去月は月末、未来月は前月末（経過0日）が初期値。CSV更新後は収録年範囲・確認日も更新してください。

### 電話番号

`libphonenumber-js` 1.13.15 の最大メタデータから日本のデータのみを使用。2〜5桁の市外局番、携帯・IP電話・フリーダイヤル等を整形します。番号の実在や接続は確認しません。海外番号、内線、その他の文章、不明な形式は原文を保持して確認を促します。コピーには未解決の行も含まれます。

## 開発と検証

```sh
npm ci
npm run build
npm test
```

`src/page.html` から4つの公開HTMLを生成し、JavaScriptを `assets/app.js` にまとめます。公開HTMLや生成済みJSを直接編集せず、ソースを編集してビルドしてください。公開時のnpmや外部CDNへの依存はありません。日本語フォントは端末標準フォントを使用します。

`tests/visual.html` は375px幅の3ツールを並べて確認する開発用ページです。自動テストでは時給境界・祝日・月初/月末・会社休日・電話番号・入力検証・コピー・ツール切替を検証します。
